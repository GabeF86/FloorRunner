## Initial findings

### Finding 1 — Forbidden "MD" in toggle button label (error)

**File:** `src/app/(scheduling)/grid-calculator/ToggleBar.tsx`
**Line:** 34
**Rule:** rule-7.5-labels-canonical (PRD §5 + §7.5)
**Severity:** **error**

```ts
options: [
  { value: 'md_heavy', label: 'MD-heavy' },          // ← rendered as a button label
  { value: 'balanced', label: 'Balanced' },
  { value: 'crna_heavy', label: 'CRNA-heavy' },
],
```

The literal string `'MD-heavy'` flows through `SECTIONS[].options[].label` and
ends up rendered inside a `<button>` in `ToggleGroup` (`ToggleBar.tsx:208`).
PRD §5 reserves "MD" for internal types only — `value: 'md_heavy'` is fine
(internal enum, also used in `CoverageStyle` and the URL query string), but
the button text must read as **"Anesthesiologist-heavy"** (or a shorter
canonical variant like **"Anes-heavy"** to match the `ANES` mono badge
elsewhere).

**Suggested fix (A9 owns the change — do NOT apply here):**

```ts
{ value: 'md_heavy', label: 'Anes-heavy' },
{ value: 'crna_heavy', label: 'CRNA-heavy' },
```

The `crna_heavy` value already pairs with a `"CRNA-heavy"` UI label, so the
symmetric fix uses the canonical UI shorthand `"Anes"` (matching the `ANES`
badge in `AnesthesiologistCard.tsx`).

### Finding 2 — Forbidden "MD" in section description tooltip (error)

**File:** `src/app/(scheduling)/grid-calculator/ToggleBar.tsx`

## Drift watch list (passes today, common drift vectors)

These are baseline-correct in the current code but are the patterns most
likely to drift in a normal week of UI tweaking. The audit script already
checks for the first two; the rest are documented for human reviewers:

1. **Tailwind blue vs cyan.** A contributor reaches for `text-blue-500`
   thinking "it's basically the same as cyan." It isn't — PRD §7.6 names
   `#0ea5e9` (cyan family) as the CRNA accent. The script flags
   `text-blue-`, `#3b82f6`, and `#2563eb` as `warn` findings.
2. **New visible "MD" labels.** Easy to drop in via copy-paste from
   `solver.ts` or `types.ts`. The script's `forbiddenInJsxText` check
   catches JSX text nodes, `label:`/`title:`/`description:` literals, and
   value/label array literals.
3. **Lane header width drift.** `width: 160` → `170` or `180` when someone
   adds an extra distance chip and "just needs a few more px." Locked
   to 160 by the A9 checkpoint. Update only on a fresh checkpoint.
4. **Card min-width drift.** `minWidth: 220` → `200` or `240`. Same logic.
5. **Shimmer duration drift.** `200ms` → `150ms` ("snappier") or `300ms`
   ("smoother"). Locked to 200ms; baseline.json carries the value.
6. **Float lane visual swap.** Outlined dashed → solid filled. PRD §7.5
   explicitly requires "outlined cards (not solid) to read as 'unassigned
   but available'." The audit's `tokenInFile` check enforces the
   `variant="float"` shape but not the dashed border style — a manual eye
   check at every weekly run is worth doing.
7. **Cross-site purple swap.** `#a855f7` → `#9333ea` (purple-600 instead
   of purple-500) or `#c084fc` (purple-300). The audit's exact-hex check
   enforces the `#a855f7` family — drift to a sibling purple is caught.
8. **FTE panel non-stickiness.** `position: 'sticky'` deleted during a
   layout cleanup. Tested via `tokenInFile`.
