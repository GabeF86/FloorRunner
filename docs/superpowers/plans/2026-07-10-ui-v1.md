# UI v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Make FloorRunner look and feel professional (one design language, one shell, real dashboard, consistent states) and expand the Claude assistant into a schedule-running copilot (read/analysis tools + broader reach).

**Architecture:** Extend the existing `globals.css` CSS-var token layer, build a zero-dependency shared component library in `src/components/ui/`, unify both shells behind one `AppShell`, and adopt incrementally (chrome passes, no monolith rewrites). Extract the AssistantPanel's generic chat plumbing into `src/components/chat/`, add read-only analysis tools to `src/lib/scheduleAssistant/tools.ts`, and mount the assistant on the schedules list. Spec: `docs/superpowers/specs/2026-07-10-ui-v1-design.md` — read it before starting any task.

**Tech Stack:** Next.js 14 App Router, React 18, TypeScript, CSS variables + inline styles (NO new UI deps, NO Tailwind migration), vitest, existing fake-supabase/fake-client fixtures.

**Conventions for every task:**
- Branch `ui-v1`. Never commit to `main`.
- Verify per task: `npm test` (baseline 425 green; the 10 gridCalculator "No test suite found" file errors are documented legacy noise) && `npx tsc --noEmit` && `npm run build`.
- TDD for anything with behavior (Modal close paths, hooks, aggregation, tools). Pure-visual components: build + adoption is the test.
- Shared components consume ONLY CSS vars — no hardcoded hex.
- Engine purity: no `src/lib/rulesEngine` changes anywhere in this plan; assistant tool executors are additive and read-only.
- The frontend-design skill should be loaded by the Task 1 implementer for aesthetic calibration before writing component styles.

```tsx
Banner: { tone: 'info'|'warn'|'error'|'success'; onDismiss?(): void; children }
Spinner: { size?: number (default 16) }
```
All styles inline consuming vars only. Barrel-export everything from `index.ts`.
